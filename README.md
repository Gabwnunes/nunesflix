Projeto escolar viabilizado pelo curso de desenvolvimento web da Alura, Cursos Online de Tecnologia. 
Abordando HTML, CSS e JavaScript ao longo de 3 anos de período letivo do ensino médio.
Propostas do Curso: 
- Construir um site utilizando HTML e CSS.
- Deploy de um site através do Github Pages ou Vercel.
- Identifique elementos e estilos através do Figma.
- Compartilhe o seu projeto com o mundo.
- Aplique seus conhecimentos adquiridos até agora em um projeto real.
- Crie um repositório para armazenar o código do projeto.
